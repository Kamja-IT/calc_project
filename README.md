# 계산기 프로젝트
### 1. 기능소개
- 더하기
```
def sum(a, b):
    return a + b
```
- 빼기
```
def sub(a, b):
    return a - b
```
- 곱하기
```
def mul(a, b):
    return a *+* b
```
- 나누기
```
def divi(a, b):
    return a/b
```
- 제곱
```
def square(a, b):
    return a ** b
```
